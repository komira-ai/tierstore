Get started

Install tierstore, start it on one machine, and put and get an object. It takes about five minutes.

Install

One command block for Linux (x86_64 or arm64) and macOS (Apple silicon). It takes the tarball of the machine it runs on, unpacks it and prints the version.

$ os=$(uname -s | sed 's/Darwin/macos/; s/Linux/linux/')
$ arch=$(uname -m | sed 's/aarch64/arm64/')
$ gh release download --repo komira-ai/tierstore \
    --pattern "tierstore-*-$os-$arch.tar.gz"
$ tar -xzf tierstore-*-$os-$arch.tar.gz tierstore
$ ./tierstore --version

No gh? Take the same file from the releases page. Verify the download before you run it.

Configure

tierstore reads one TOML file. Make a key file, which holds an access key id and a secret on two lines, and two directories for the tiers.

$ printf 'AKIDEXAMPLE\nexample-secret-change-me\n' > access.key
$ chmod 0600 access.key
$ mkdir hot cold

Then write the file for the shape you run, as tierstore.toml next to access.key.

Both tiers are directories on this machine. Start here.

[[interface]]
type   = "s3"
params = { addresses = ["127.0.0.1:9000"] }

[server]
proxy_id        = "tierstore-1"
bucket          = "tierstore"
access_key_file = "access.key"

[hot_store]
kind   = "dir"
path   = "hot"
budget = "1GiB"

[cold_store]
kind = "dir"
path = "cold"

A fast hot tier in front of a large cold tier, on a private address, with a read-only key for programs that only read.

[[interface]]
type   = "s3"
params = { addresses = ["192.0.2.10:9000"] }

[server]
proxy_id            = "tierstore-1"
bucket              = "tierstore"
access_key_file     = "/etc/tierstore/access.key"
read_only_key_files = ["/etc/tierstore/daemons.key"]

[hot_store]
kind   = "dir"
path   = "/srv/tierstore/hot"
budget = "800GiB"

[cold_store]
kind = "dir"
path = "/srv/tierstore/cold"

A cache on local disk in front of one upstream store, for a machine that mostly reads.

[[interface]]
type   = "s3"
params = { addresses = ["127.0.0.1:9400"] }

[server]
proxy_id        = "tierstore-cache-1"
bucket          = "tierstore"
access_key_file = "/etc/tierstore-cache/access.key"

[local_cache]
path   = "/var/lib/tierstore-cache"
budget = "40GiB"

[cold_store]
kind             = "s3"
bucket           = "tierstore"
endpoint         = "http://s3-cold.example:9000"
credentials_file = "/etc/tierstore-cache/upstream-read.key"

[[policy]]
prefix = "cas/b/"
cache  = true

Every other setting keeps its default. The configuration guide explains these shapes and the reference lists every key.

Run

Start tierstore. It prints its version and the address it listens on, and serves one bucket until you press Ctrl-C.

$ ./tierstore --config tierstore.toml

In another terminal, put an object and get it back with the aws CLI. The key is the one in access.key.

$ export AWS_ACCESS_KEY_ID=AKIDEXAMPLE
$ export AWS_SECRET_ACCESS_KEY=example-secret-change-me
$ export AWS_DEFAULT_REGION=us-east-1
$ aws configure set default.s3.addressing_style path
$ echo hello > hello.txt
$ aws --endpoint-url http://127.0.0.1:9000 s3api put-object \
    --bucket tierstore --key hello.txt --body hello.txt
$ aws --endpoint-url http://127.0.0.1:9000 s3api get-object \
    --bucket tierstore --key hello.txt out.txt
$ cat out.txt

Use it from your code

Point any S3 client at the address, with path-style addressing, the region us-east-1 and the key from access.key. tierstore has no credentials of its own.

$ export AWS_ACCESS_KEY_ID=<key id> AWS_SECRET_ACCESS_KEY=<secret> AWS_DEFAULT_REGION=us-east-1
$ aws configure set default.s3.addressing_style path
$ aws --endpoint-url http://tierstore.example:9000 s3api put-object --bucket tierstore --key hello.txt --body hello.txt
$ aws --endpoint-url http://tierstore.example:9000 s3api list-objects-v2 --bucket tierstore
import boto3
from botocore.config import Config

client = boto3.client(
    "s3",
    endpoint_url="http://tierstore.example:9000",
    region_name="us-east-1",
    aws_access_key_id=KEY_ID,
    aws_secret_access_key=SECRET,
    config=Config(
        signature_version="s3v4",

        request_checksum_calculation="when_required",
        response_checksum_validation="when_required",

)
