A hot tier in front of a cold store, behind one S3 endpoint.

tierstore is an S3 server in front of a small, fast store and a large, cheap one. Your programs see one bucket and talk to it with any S3 client.

Install Read the docs

Two tiers, one bucket

  • New objects go to the fast tier

    A write is confirmed as soon as the hot tier has the object.

  • The large tier catches up quietly

    In the background, tierstore copies new objects to the cold tier.

  • Old objects make room

    When the hot tier fills, the objects written longest ago that the cold tier already has are removed.

  • Reads look in the fast tier first

    An object only in the cold tier is read from there and copied back to the hot tier.

To see why tierstore exists, read the technical report (on komira.ai). For the settings and for running it, see the docs; to watch a start and a drain, see the demo.

What is built, and what is not

tierstore is in early development and open source under the Apache 2.0 licence. This is what works today.
