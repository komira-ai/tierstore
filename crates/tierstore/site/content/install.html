Install

One command. Then check what you installed.

From the next release The script reads the newest release from tierstore.dev, downloads the tarball of your machine (Linux x86_64 or arm64, macOS Apple silicon), refuses unless its SHA-256 matches, and puts tierstore in ~/.local/bin. It starts nothing. Until a release is published there, use the Tarball tab.

$ curl -fsSL https://tierstore.dev/install.sh | sh

From the next release The tap komira-ai/tap has the formula for macOS on Apple silicon and for Linux. Until a release has it, use the Tarball tab.

$ brew install komira-ai/tap/tierstore

From the next release The package tierstore is in the repository packages.komira.ai. The block fetches the repository's key, trusts it for this source only, and installs. Until a release has it, use the Tarball tab.

sudo install -d -m 0755 /usr/share/keyrings
sudo curl -fsSL https://packages.komira.ai/apt/komira-archive-keyring.gpg -o /usr/share/keyrings/komira-archive-keyring.gpg
sudo tee /etc/apt/sources.list.d/komira.sources >/dev/null <<'EOF'
Types: deb
URIs: https://packages.komira.ai/apt
Suites: stable
Components: main
Signed-By: /usr/share/keyrings/komira-archive-keyring.gpg
EOF
sudo apt update
sudo apt install tierstore

Works today One block for Linux (x86_64 or arm64) and macOS (Apple silicon). It takes the tarball of the machine it runs on from the latest release on GitHub, with its signature bundle and SHA256SUMS for the checks below, unpacks it and prints the version.

$ os=$(uname -s | sed 's/Darwin/macos/; s/Linux/linux/')
$ arch=$(uname -m | sed 's/aarch64/arm64/')
$ gh release download --repo komira-ai/tierstore \
    --pattern "tierstore-*-$os-$arch.tar.gz*" --pattern SHA256SUMS
$ tar -xzf tierstore-*-$os-$arch.tar.gz tierstore
$ ./tierstore --version

Next: configure it. One small file, then a put and a get.

Verify

Three checks, in this order. The first proves the download is intact; the second or the third proves that this repository built and signed it. The second needs gh with the gh attestation command; the third needs only cosign. <commit> is the full commit SHA in the tarball's name, and <tarball> is the tarball's file name, tierstore-<commit>-linux-x86_64.tar.gz for instance. Run the checks in the directory that holds the tarball, its .sigstore.json bundle and SHA256SUMS, all from one release.

Integrity

The checksum file lists every platform's tarball, so --ignore-missing skips the ones you did not take. It proves the file is intact, not who built it.

sha256sum -c --ignore-missing SHA256SUMS

Authenticity with gh

--source-digest makes the check prove the build came from that commit, not only from the main workflow.

gh attestation verify tierstore-<commit>-linux-x86_64.tar.gz --repo komira-ai/tierstore \
  --signer-workflow komira-ai/tierstore/.github/workflows/artifacts.yml \
  --source-ref refs/heads/main --source-digest <commit> --deny-self-hosted-runners

Authenticity without gh

This needs only cosign. It prints Verified OK. --type slsaprovenance1 is required: without it cosign fails with "invalid predicate type".

cosign verify-blob-attestation \
  --bundle <tarball>.sigstore.json \
  --type slsaprovenance1 \
  --certificate-identity-regexp '^https://github.com/komira-ai/tierstore/\.github/workflows/artifacts\.yml@refs/heads/main$' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  <tarball>

On a host with no network

Fetch the trusted root on a host that has a network, copy it over with the tarball and its bundle, and verify against the bundle.

gh attestation trusted-root > trusted_root.jsonl
gh attestation verify <tarball> --repo komira-ai/tierstore \
  --bundle <tarball>.sigstore.json --custom-trusted-root trusted_root.jsonl \
  --signer-workflow komira-ai/tierstore/.github/workflows/artifacts.yml \
  --source-ref refs/heads/main --source-digest <commit> --deny-self-hosted-runners

Every check names one signer: the workflow .github/workflows/artifacts.yml of this repository, run on refs/heads/main. The binary for macOS is ad-hoc signed and not notarized; gh release download and curl save it without the quarantine attribute, so it runs.
