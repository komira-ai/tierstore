# tierstore

An S3-compatible object store front with two tiers behind it, and a read cache for build nodes.

tierstore lives in this repository: from 0.3.0 every release is built and signed here (versions up to 0.2.0 were built
elsewhere). Download a release from the [releases page](https://github.com/komira-ai/tierstore/releases) and verify it with
[docs/ci-and-release.md](docs/ci-and-release.md).

The rules every change to this repository is written and reviewed against are in [AGENTS.md](AGENTS.md).
